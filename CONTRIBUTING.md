

# Contributing to Native State

🎉 First off, thank you for considering contributing to **Native State**! Your help makes this project better for everyone.

## 📋 Code of Conduct
This project follows the [Contributor Covenant Code of Conduct](https://www.contributor-covenant.org/).  
By participating, you agree to uphold this standard of respectful and inclusive collaboration.

## 🛠 How to Contribute

### Reporting Issues
- Use the `[Looks like the result wasn't safe to show. Let's switch things up and try something else!]` tab to report bugs or request features.
- Before opening a new issue, please check if it already exists.
- Include clear steps to reproduce bugs, expected vs. actual behavior, and environment details (OS, Node.js version, etc.).

### Suggesting Enhancements
- Clearly describe the problem your suggestion solves.
- Provide examples or mockups if possible.
- Keep proposals focused and actionable.

### Submitting Pull Requests
1. **Fork** the repository.
2. **Create a branch** for your changes:
   ```bash
   git checkout -b feature/my-new-feature
   ```
3. **Make your changes** with clear, concise commits.
4. **Run tests** (if available) to ensure nothing breaks.
5. **Push your branch** and open a Pull Request (PR).
6. In your PR description:
   - Explain the problem and solution.
   - Reference related issues (e.g., `Closes #42`).
   - Add screenshots or examples if relevant.

### Coding Guidelines
- Follow existing code style and conventions.
- Keep commits atomic and messages descriptive.
- Write or update tests for new functionality.
- Document public APIs and components.

### Documentation Contributions
- Improve README, examples, or inline comments.
- Fix typos, clarify instructions, or add missing details.
- Contributions to docs are just as valuable as code!

## ✅ Development Setup
1. Clone the repo:
   ```bash
   git clone https://github.com/sarath263/native-state.git
   cd native-state
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the project/tests:
   ```bash
   npm run build
   npm test
   ```

## 🔄 Release Process
- Maintainers handle versioning and publishing.
- Contributors may suggest release notes in PRs.

## 🙌 Recognition
All contributors will be listed in the `repository` page.  
We appreciate every bug report, feature request, and line of code!
